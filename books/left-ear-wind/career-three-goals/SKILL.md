# 程序员职业发展三目标模型（职场→经历→自由）

## R — 原文 (Reading)

> 程序员的职业发展有三个层次的目标。第一层是职场目标——找到好工作、拿到好offer。第二层是经历目标——追求有价值的经历，做有意义的事，而不是追求安逸。第三层是自由目标，分为三层：工作自由（随时能找到好工作）、技能自由（靠技能养活自己，不需要公司）、物质自由（通过投资和杠杆实现财务自由）。
>
> — 陈皓, 第7章 程序员修炼之道

---

## I — 方法论骨架 (Interpretation)

这个模型将程序员的职业发展分解为三层递进的目标体系，每层有明确的达成标志和过渡条件。

**第一层：职场目标**
核心任务是"打好基础、进入好平台"。标志是能在好公司找到好工作。这一层解决的是"生存"问题——有稳定的收入、有学习环境、有职业起点。大多数人停留在这一层。

**第二层：经历目标**
核心任务是"追求有价值的经历而非安逸"。标志是简历上有一系列有分量的项目经历（如"从0到1构建了XX系统"、"帮助XX解决了XX难题"）。这一层解决的是"成长"问题——从"在公司里做事"转变为"做出有影响力的事"。关键是主动选择挑战而非被动接受安排。

**第三层：自由目标**
这是一个三层嵌套的自由阶梯：
1. **工作自由**: 能力足够强，随时能找到好工作。标志是"不怕被裁员"
2. **技能自由**: 靠自己的技能独立养活自己，不需要依附任何公司。标志是"不靠工资也能生存"
3. **物质自由**: 通过投资和杠杆实现财务自由。标志是"不靠工作也能维持生活"

**核心洞察**: 大多数人只追求第一层（好工作），少数人追求第二层（好经历），极少人意识到第三层有三个子层级且可以逐步达成。不要直接跳到"创业"，那需要多层自由都具备。

## A1 — 书中的应用 (Past Application)

### 案例 1: 从银行到上海到北京的完整职业迁移
- **问题**: 1998年毕业后在银行工作两年，面临"安于银行铁饭碗 vs 出去闯荡"的选择
- **方法论的使用**: 作者评估自己在"职场目标"层已达成（有稳定工作），但在"经历目标"层完全空白（银行技术含量低、没有有价值的经历）。决策是追求经历而非安逸——先到上海再到北京
- **结论**: 放弃银行的房子和稳定，投身互联网大潮
- **结果**: 虽然初到上海正值互联网泡沫、面试屡屡碰壁，但最终进入汤森路透、亚马逊、阿里等顶尖公司，积累了银行→金融数据→电商→分布式系统的跨领域经历

### 案例 2: 辞去阿里工作兼职"打零工"发现创业方向
- **问题**: 39岁时父亲病危、工作压力大，面临"留在阿里 vs 出来"的选择
- **方法论的使用**: 作者在"职场目标"层早已完成，在"经历目标"层也已积累丰厚。现在需要验证"技能自由"——不靠阿里这个平台，仅靠自己的技术能力能否养活自己和团队
- **结论**: 不加入任何公司，不动积蓄，不接受投资，仅靠为别人解决技术难题生存
- **结果**: 成功养家并聘请3名工程师，验证了"技能自由"的可行性。同时发现了市场对分布式技术架构服务的需求，直接催生了MegaEase创业

### 案例 3: 降薪降职加入亚马逊追求经历
- **问题**: 在汤森路透已是重点培养对象，面临"安于现状 vs 降薪求变"的选择
- **方法论的使用**: 用"经历目标"来评估——汤森路透的经历已经获得，亚马逊能带来全新的经历（电商、大规模分布式系统、不同的工程文化）。追求有价值的经历比追求薪资增长更重要
- **结论**: 降薪降职去亚马逊
- **结果**: 学到了5-Why分析、数据驱动决策、算法指挥生产等核心经验，这些经历的价值远超短期薪资差异

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. **职业瓶颈焦虑** — 在大厂做了3-5年，薪资不错但感觉在重复劳动，不知道下一步该怎么走
2. **中年危机前兆** — 30岁左右开始焦虑"35岁以后怎么办"，纠结要不要转管理
3. **想离职创业** — 有创业想法但不确定自己是否准备好了，害怕失去稳定收入
4. **offer选择困难** — 拿到多个offer，一个薪资高但做的事没意思，一个做的事有意思但薪资低
5. **感到被困住** — 觉得自己"离不开这家公司"、"只会做这个"，缺乏选择权

### 语言信号 (用户的话里出现这些就应激活)

- "程序员35岁以后怎么办？"
- "该不该转管理？"
- "想离职创业但又怕..."
- "在大厂做几年了接下来怎么走？"
- "感觉自己被困在这家公司了"
- "不想一辈子打工..."
- "我该怎么规划职业发展？"
- "我想做自己的事但不敢离开..."

### 与相邻 skill 的区分

- 与 `do-right-things` 的区别: 本skill是职业大方向的阶段规划（"我该往哪走"），do-right-things 是具体一件事的价值判断（"这件事值不值得做"）
- 与 `competency-leap` 的区别: 本skill定义的是目标（"要到哪里去"），competency-leap 定义的是能力路径（"怎么提升竞争力去到那里"）
- 与 `time-value-invest` 的区别: 本skill是职业层面的战略规划，time-value-invest 是日常时间分配的战术工具

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定位用户当前所处阶段**
   - 用诊断问题逐层确认:

   ```markdown
   ### 职业阶段诊断

   | 层级 | 诊断问题 | 判定 |
   |------|---------|------|
   | 职场目标 | "你能稳定找到好工作吗？" | ✓已达成 / ✗未达成 |
   | 经历目标 | "简历上有从0到1或有分量的项目经历吗？" | ✓已达成 / ✗未达成 |
   | 工作自由 | "如果明天被裁员，你能做什么？" | ✓已达成 / ✗未达成 |
   | 技能自由 | "不靠公司，你的技能能独立变现吗？" | ✓已达成 / ✗未达成 |
   | 物质自由 | "不靠工作也能维持生活吗？" | ✓已达成 / ✗未达成 |
   ```

   - 判停条件: 若用户连"职场目标"层都未达成，建议先回到 `competency-leap` 提升核心竞争力

2. **明确下一层目标和当前差距**
   - 输出格式:

   ```markdown
   **当前阶段**: [X]层
   **下一目标**: [X+1]层
   **关键差距**: [具体描述1-2个最大差距]
   **行动选项**:
   - [ ] 选项A: [如: 主动申请一个从0到1的项目]
   - [ ] 选项B: [如: 参与开源项目积累经历]
   - [ ] 选项C: [如: 在团队中推动一个有挑战的技术方案]
   ```

   - 判停条件: 若用户想跳过中间层直接追求高阶自由，明确警告风险并建议按顺序推进

3. **输出阶段性行动计划**
   - 按以下模板输出:

   ```markdown
   ### [时间范围] 行动计划

   **阶段性目标**: [如: 在未来半年内积累一个有分量的项目经历]
   **成功标准**: [可衡量的指标]

   | 行动项 | 时间 | 关键产出 |
   |--------|------|---------|
   | [如: 参与开源项目X] | [第1-2月] | [如: 贡献3个PR] |
   | [如: 推动技术方案Y] | [第3-4月] | [如: 方案上线并文档化] |
   | [如: 写技术博客总结] | [第5-6月] | [如: 发布3篇深度文章] |
   ```

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **应届生求职**: 刚毕业的程序员第一要务是"找到工作"（职场目标层的基础），不需要规划三层自由体系
- **短期跳槽决策**: 如果只是"在A公司和B公司之间选哪个薪资更高"，不涉及职业方向，不适合用这个模型
- **非技术职业路径**: 本模型基于技术能力的递进，对想转行做产品、运营、投资的人不适用

### 作者在书中警告的失败模式

- **为逃避而选择 (ce03)**: 如果去创业公司/创业的动机是"逃离当前困境"而非"追求某个目标"，到了新环境问题依旧甚至更多。三目标模型要求以"追求什么"为起点
- **追求安逸的舒适区陷阱 (ce21)**: 在舒适区中待太久，能力单一化，与行业前沿脱节。三目标模型明确反对在"经历目标"层追求安逸
- **35岁危机自我实现的预言 (ce17)**: 相信"程序员35岁就没用了"，在应该深耕技术的阶段分心去做"退路"准备。三目标模型的核心洞察是：30岁是编程的起点而非终点，关键是持续积累到"技能自由"层
- **投机者心态 (ce05)**: 追求短期利益和表面成功，把精力花在"捷径"上。三目标模型要求每层都有扎实的能力积累，没有捷径
- **选择困难与决策瘫痪 (ce27)**: 在选择面前犹豫不决，目标不清晰时无法建立评判标准。三目标模型的价值正是提供清晰的评判标准

### 作者的盲点 / 时代局限

- "三层自由"的递进模型基于互联网黄金时代的个人经历，在经济下行期"技能自由"和"物质自由"的达成难度远高于作者的假设
- 未充分考虑家庭因素对职业选择的影响——不是所有人都有条件"辞去高薪去追求经历"
- "物质自由"通过投资实现的部分缺乏具体方法论，更多是一个方向性指引
- 幸存者偏差：作者是极少数同时实现了三层自由的人，大多数人在第一二层就遇到了天花板（行业周期、公司裁员、家庭负担等）
- 对"不选择安逸"的推崇可能不适合所有人——有人选择安稳是理性的风险规避，而非缺乏追求

### 容易混淆的邻近方法论

- 三目标模型 vs "升职加薪": 前者是纵向的能力自由度递进，后者是横向的职位/薪资提升。在大公司从P6升到P8不代表实现了"经历目标"
- 三目标模型 vs "FIRE运动": 前者强调技能自由先于物质自由，后者直接追求物质自由（攒够钱就退休）。作者认为"技能自由"比"物质自由"更重要也更可控
