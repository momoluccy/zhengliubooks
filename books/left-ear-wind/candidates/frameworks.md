  title: 五步思考法
  type: framework
  source_chapter: 第5章
  source_quote: |
    "第一步:考证信息数据的正确性。第二步:处理集合及其包含关系。第三步:处理逻辑因果关系。第四步:找到可信的基准线。第五步:开启更为深入和高维度的思考。五步思考法倡导的是一个'慢思考'的过程。"
  summary: |
    一个系统化的独立思考框架，通过五个递进步骤对抗浅度思考：先考证数据真伪，再用集合/包含关系检验逻辑范围，接着区分充分/必要/充要条件确认因果，然后找业内基准线对标，最后通过"5个为什么"进行高维深挖。核心是调用大脑的"慢系统"进行反直觉的深度推理。
  tags: [独立思考, 慢思考, 信息甄别, 逻辑推理, 5-Why]

  type: framework

- id: f04
  title: 系统学习技术模板
  type: framework
  source_chapter: 第8章
  source_quote: |
    "学习技术的背景、初衷、要达到的目标或要解决的问题。学习技术的优势和劣势。学习技术的适用场景。学习技术的核心组成部分和关键点。学习技术的底层原理和关键实现。学习技术与已有实现的对比。"
  summary: |
    一套可复用的技术学习SOP，包含六个维度：1)背景与目标（为什么出现）；2)优势与劣势（权衡取舍）；3)适用场景（什么场景用什么不合适）；4)核心组件（快速抓住精髓）；5)底层原理（跨技术通用的部分）；6)与已有实现对比（开阔思路）。按此模板学习两到三年可成为领域佼佼者。
  tags: [学习方法, 技术学习, SOP, 知识图谱]

- id: f05
  title: 做正确的事的决策框架
  type: framework
  source_chapter: 第4章
  source_quote: |
    "正确的事情应该能够给公司或个人带来长期收益。正确的事情应该能够使公司或个人有质的提高或成长。正确的事情应该能够提高效率。正确的事情应该能够解放生产力。正确的事情应该能够增强公司或个人的竞争力。"
  summary: |
    面对"该不该做某件事"的决策时，用五个标准逐条检验：1)是否带来长期收益（非短期）；2)是否促进质的成长（非量变）；3)是否提高效率（有用功/总功）；4)是否解放生产力（消除无谓流程）；5)是否增强竞争力（创造更多可能性）。满足条件越多，事情越"正确"。
  tags: [决策框架, 长期主义, 效率, 生产力]

  tags: [技术选型, 决策框架, 投资评估, 技术趋势]

- id: f09
  title: 编程本质三要素框架（Logic+Control+Data）
  type: framework
  source_chapter: 第10章
  source_quote: |
    "Program = Logic + Control + Data Structure。逻辑是指业务逻辑和逻辑过程的抽象。控制逻辑与业务逻辑没有关系，你控制，它执行。有效地分离Logic、Control和Data是写出好程序的关键所在。"
  summary: |
    将编程本质抽象为三个正交维度：Logic（业务逻辑——问题的本质）、Control（控制逻辑——解决问题的策略，如遍历、并发、异步）、Data（数据结构——问题的表现形式）。所有编程范式（面向对象、函数式、逻辑编程）都是在解决这三者的分离问题。程序复杂度的根源是Logic和Control的纠缠，解耦手段包括状态机、DSL和编程范式。
  tags: [编程范式, 代码设计, 抽象, 程序本质]

  type: framework
  source_chapter: 第16章
  source_quote: |
    "产品经理会评估每个需求的业务影响力，并用T恤尺码中的XXXL号表示可能影响的千万量级的用户或占据的一亿美元市场……开发团队也会评估人员投入的时间成本。当业务影响力为XL、时间成本为S时，需求拥有最高优先级。"
  summary: |
